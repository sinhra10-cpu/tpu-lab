定義と測り方

恥骨結合pubic symphysisの長軸と、恥骨下縁から児頭骨性先進部へ引いた接線とのなす角度。児頭が下降するほど角度は大きくなります。

画面上(12時)がプローブ=会陰。頂点は恥骨結合の下縁、黄線 = 恥骨結合長軸(延長線)、青線 = 児頭骨性部への接線。児頭は必ずこの2線で挟まれた角の内側にあります。陣痛間欠期・いきみのない状態で測定します。

児頭会陰間距離 Head–Perineum Distance (HPD)

TPU · TRANSVERSE 横断 · probe 12時
154070 mm

定義と測り方

横断面で、児頭骨性外縁から会陰皮膚表面までの最短距離。プローブで会陰の軟部組織を恥骨方向へ十分に圧迫してから測ります(圧迫不足は過大評価の原因)。

画面上(12時)がプローブ=会陰皮膚、下へ行くほど深部。プローブ角度を振って最短距離が得られる位置を探します。

児頭方向 Head Direction (HD)

TPU · MID-SAGITTAL 正中矢状断
−30°0°30°60°

定義

正中矢状断で、認識できる児頭の最長軸と恥骨結合長軸とのなす角。head down(<0°)・horizontal(0〜30°)・head up(>30°)の3分類で読みます。児頭が骨盤底に向かって下降するにつれ、下向き → 水平 → 上向きへ変化します。

正中線角度 Midline Angle (MLA)

TPU · TRANSVERSE 横断
0° (回旋完了)45°90° (横向き)

定義

横断面で、児頭正中線エコーcerebral midlineと母体骨盤前後軸AP axis of the pelvisのなす角度。内回旋internal rotationが進むほど0°に近づきます。正中線が描出できないこと自体も「まだ高い」ことの所見になります。

海外の教科書・ガイドラインでの扱い

Station(DeLee): 坐骨棘間平面を 0 とし、骨性先進部の位置を −5〜+5 cm で表す。坐骨棘は内診で4時・8時方向に触れる。頭位では先進部が station 0 に達した時点で嵌入とする(Gabbe's Obstetrics)。

Hodge 平面: O面 = 恥骨結合上縁と岬角を結ぶ面(骨盤入口)、U面 = 恥骨結合下縁を通る平行面、I面 = 坐骨棘間平面、B面 = 骨盤出口面。U面は坐骨棘間平面の 4 cm 上にあたります(Weitzel & Hopp 1998)。

恥骨結合の触知範囲: 今回確認した海外の教科書・ガイドラインでは、恥骨結合後面の触知範囲を station の尺度としては用いていません。恥骨結合は Hodge 平面(O面・U面)の基準として使われています。

内診で追うのは骨性先進部であり、産瘤(caput)ではありません。産瘤を先進部と誤認すると station を低く見積もります。

腹部触診での下降度 fifths palpable

骨盤入口より上に触れる児頭を5分の何で表します。5/5 = 児頭全体が入口より上、2/5 = 児頭の大部分が入口より下で嵌入、1/5 = 児頭の先端のみ触れる。3/5 と 2/5 の区別が特に重要です。

5分法と cm 単位の station を1対1で換算する信頼できる表は見つからなかったため、換算は示していません。

手技と臨床での使い方 Technique & clinical use

基本の手順

  1. 膀胱を空にし、仰臥位・膝屈曲位で準備。プローブは清潔カバーで覆う。
  2. 正中矢状断: 恥骨結合の直下、大陰唇の間にコンベックスプローブを縦に当て、恥骨結合長軸と児頭を同一画面に描出 → AoP・児頭方向。
  3. 横断: プローブを90°回して会陰を圧迫 → HPD・正中線角度。
  4. 測定は陣痛間欠期、いきみのない状態で。
  5. 児頭の向きocciput positionそのものは経腹エコーで確認する(低い位置では経会陰でも可)。
  6. AoP の換算は ISUOG ガイドライン掲載の表(Tutschek 2013)に準拠:−3 = 84°、0 = 116°、+1 = 127°、+2 = 138°、+5 = 170°。
  7. 得られた所見を St タブに入力し、児頭下降度を総合的に評価する。

ISUOG ガイドラインの要点 ISUOG Practice Guidelines 2018

経腟内診による station・回旋評価は主観的で検者間差が大きく、超音波は児頭の下降度を客観的に記録できます。器械分娩instrumental vaginal deliveryの前には、児頭の向きを経腹で、下降度を経会陰で評価することが推奨されています。

落とし穴 pitfalls

産瘤caput succedaneumや骨重積moldingがあると、内診では実際より低く感じます。超音波は骨性先進部で測るので、ここが内診との差が出やすい場面です。

本ツールの数値は教育目的の目安です。分娩方針は施設の基準と臨床所見を総合して決めてください。
